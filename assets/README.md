# RastrIO Assets

This directory contains the production brand, application, README, and social assets for RastrIO.

See [`ASSETS.md`](./ASSETS.md) for the authoritative asset manifest, logo construction rules, safe-area guidance, and usage requirements.

```text
assets/
├── brand/
│   ├── app/       # Android adaptive-icon sources
│   ├── icons/     # Favicons and app/project icons
│   └── logo/      # Canonical symbol and wordmark assets
├── readme/        # Repository hero and supporting artwork
└── social/        # Social/repository preview graphics
```

`brand/logo/rastrio-symbol.svg` is the canonical logo geometry. Do not redraw or regenerate production logo variants independently.
