# Pinned logical-preview font

JetBrains Mono Regular 2.304, unmodified, under SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304
File: https://raw.githubusercontent.com/JetBrains/JetBrainsMono/v2.304/fonts/ttf/JetBrainsMono-Regular.ttf
SHA-256: a0bf60ef0f83c5ed4d7a75d45838548b1f6873372dfac88f71804491898d138f

The hhea metrics are ascent 1020, descent -300, gap 0, with 1000 units/em.
Printable ASCII glyph advances are 600 units. Authoring uses 3 mm/em body,
with heading scales 1.8, 1.6, 1.4, 1.2, 1.1, 1.0. This is a restricted
production configuration of the existing Core ASCII fixed-cell backend.
Unsupported scripts fail with Core diagnostics. Bold/italic are representative
synthetic painting over the same supplied metrics; no printer-font fidelity is claimed.
The logical canvas defaults to 120 mm; it is not a printer-paper constraint.
No font download or other network access happens at runtime.
